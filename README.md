# Beauty Life Centro Estético — React website

A responsive Spanish-language landing page built with React, Vite, Lucide icons, and custom CSS.

## Run locally

1. Install Node.js (LTS).
2. In this folder run `npm install`.
3. Run `npm run dev` and open the local URL shown by Vite.
4. Run `npm run build` to create the production build in `dist/`.

## Notes
- Appointment CTA opens WhatsApp at +593 99 927 2654 with the requested prefilled Spanish message.
- Address opens a Google Maps search for the supplied Quito address.
- Email, Instagram, Facebook, Linktree and TCP IT Solution credit use the supplied destinations.
- The year is generated dynamically.
- The image assets are loaded from Unsplash URLs and require internet access.
